# SimpleColors and migrating to DDD

Generated by `scripts/generate-ddd-references.js` from `elements/simple-colors-shared-styles/simple-colors-shared-styles.js` and `elements/simple-colors/simple-colors.js`. Do not edit by hand.

SimpleColors is the extended palette DDD builds on. Use DDD first; reach for SimpleColors only when DDD has no workable colour (charts, instructional-action icons, palettes, the `accent-color` attribute).

## Structure

- 19 hues: `grey`, `red`, `pink`, `purple`, `deep-purple`, `indigo`, `blue`, `light-blue`, `cyan`, `teal`, `green`, `light-green`, `lime`, `yellow`, `amber`, `orange`, `deep-orange`, `brown`, `blue-grey`. 12 shades each, 1 (palest) to 12 (deepest).
- `--simple-colors-default-theme-<hue>-<n>` follows dark mode: under `[dark]`, shade n takes the value of shade 13−n.
- `--simple-colors-fixed-theme-<hue>-<n>` never changes. Use it for brand fills, charts and palette swatches.
- `--simple-colors-default-theme-accent-<n>` follows the element's `accent-color` attribute (grey when unset). Shade 7 is the CSS `accent-color`.
- Dark mode is not a pure inversion for `cyan-12` (`#ddf8ff`, not `#ccf3fd`), `teal-12` (`#d9fff0`, not `#d4ffee`).

## Contrast rule (WCAG AA)

For text of shade N on another hue, the compliant shades of that hue. Grey pairs use the `greyColor` row; two colours use `colorColor`. "Large" means 18pt+ or bold 14pt+.

## Migration

1. Find the SimpleColors variable and its hex below.
2. If the nearest DDD token is a close match (ΔE under 10, marked ✓), replace it with that token, or with the `--ddd-primary-N` / `--ddd-accent-N` that aliases it when the colour is a theme choice.
3. Otherwise keep SimpleColors: DDD has no equivalent. Prefer the `fixed` variant unless the colour should flip in dark mode.
4. Re-check contrast for every text/fill pair you change, in light and dark.
5. Note any SimpleColors that remains, and why, in the component's README.

ΔE is CIE76 distance in Lab: under 2 is imperceptible, under 10 reads as the same colour, above 20 is a different colour.
