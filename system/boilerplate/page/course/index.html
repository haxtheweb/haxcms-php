What can I do?

HAX comes with a lot of blocks that do a lot with very little effort. Here are a few things to try first. If you already know your way around, delete this content and have fun!

  1. Select Edit in the top bar, then click any text on this page to change it
  2. Press Enter at the end of a paragraph to start a new one
  3. Open Merlin to search everything you can add or do
  4. Change the video next to this list, or add a new one
